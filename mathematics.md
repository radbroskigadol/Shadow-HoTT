# Mathematical core: exact Clifford label transport

## Objects

For `n >= 1`, let `P_n = {I, X, Y, Z}^{⊗n}` be the set of unsigned Pauli words modulo global phase. Shadow-HoTT's exact transport layer works over signed Hermitian Pauli observables

```text
P_n^± = { +P, -P : P in P_n }.
```

A label such as `+XYZ` denotes the signed observable `+(X ⊗ Y ⊗ Z)`.

## Implemented Clifford generators

The exact transport layer implements:

- `H_i`, Hadamard on wire `i`;
- `S_i`, phase gate on wire `i`;
- `Sdg_i`, inverse phase gate on wire `i`;
- `X_i`, `Y_i`, `Z_i`, Pauli gates interpreted by conjugation;
- `CNOT_{c->t}` / `CX_{c->t}`, controlled-NOT from control `c` to target `t`;
- `CZ_{a,b}`, controlled-Z on wires `a,b`;
- `SWAP_{a,b}`, wire swap on wires `a,b`.

Each acts by Clifford conjugation on signed Pauli observables.

## Local single-wire rules

Hadamard:

| input | output | sign |
|---|---|---|
| I | I | + |
| X | Z | + |
| Y | Y | - |
| Z | X | + |

Phase gate `S`:

| input | output | sign |
|---|---|---|
| I | I | + |
| X | Y | + |
| Y | X | - |
| Z | Z | + |

Inverse phase gate `Sdg`:

| input | output | sign |
|---|---|---|
| I | I | + |
| X | Y | - |
| Y | X | + |
| Z | Z | + |

Pauli conjugation gates:

| gate | X input | Y input | Z input |
|---|---|---|---|
| X | +X | -Y | -Z |
| Y | -X | +Y | -Z |
| Z | -X | -Y | +Z |

## Two-wire rules

CNOT uses standard generator images:

| input | output |
|---|---|
| `XI` | `XX` |
| `ZI` | `ZI` |
| `IX` | `IX` |
| `IZ` | `ZZ` |

CZ uses standard generator images:

| input | output |
|---|---|
| `XI` | `XZ` |
| `ZI` | `ZI` |
| `IX` | `ZX` |
| `IZ` | `IZ` |

SWAP simply exchanges the two local Pauli letters, preserving the sign.

Arbitrary local CNOT and CZ pairs are generated by multiplying the images of `(P_a, I)` and `(I, P_b)` with the Pauli product table and reducing the resulting Hermitian phase to `±1`.

## Soundness theorem

For every implemented Clifford operation `g`, the engine transport map `tau_hat_g : P_n^± -> P_n^±` equals Clifford conjugation:

```text
tau_hat_g(sigma P) = g (sigma P) g†.
```

The code-level harness checks:

- `H^2 = I` on signed Pauli labels;
- `S^4 = I` on signed Pauli labels;
- `Sdg` is inverse to `S` on signed Pauli labels;
- `X^2 = Y^2 = Z^2 = I` on signed Pauli labels;
- `CNOT^2 = I`, `CZ^2 = I`, and `SWAP^2 = I` on signed Pauli labels;
- single-generator image sanity checks.

Run:

```bash
python -c "from shadow_hott import verify_transport_soundness; print(verify_transport_soundness(max_qubits=3))"
```

## Boundary of the theorem

The theorem covers exact Clifford label transport only. It does not prove the bilateral truth/falsity score layer, the thresholding policy, the deterministic measurement proxy, or compiler-route optimality. Those are diagnostic overlays built on top of the exact transport kernel.
